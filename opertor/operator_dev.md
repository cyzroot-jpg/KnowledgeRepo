# Operator

## 1. 算子开发流程
```bash
算子分析：主要是分析算子的数学计算逻辑、输入输出数据，并明确算子的实现流程。

算子实现：实现算子计算逻辑的核心步骤，包括：

    申请主机端内存，并搬运输入数据

    申请Global存储空间，并搬运输入数据（主机端至Global）

    申请SPM存储空间，并搬运输入数据（Global至SPM）到SPM进行计算，计算结果存储在SPM。

    搬运输出数据（SPM至Global）

    搬运输出数据（Global至主机端）

    算子测试

编译运行：开发完成的算子，编译运行后可以获得目标结果。
```
