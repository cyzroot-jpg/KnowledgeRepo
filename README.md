### 📦 npm

- 📄 [`npm.md`](./npm/npm.md) — npm 使用指南

- 📄 [`oop/README.md`](./Python/oop/README.md) — Python 面向对象课程首页

### 🤖 OpenCode

### 🧠 LLM 从 0 到 1

从零实现并训练一个字符级 GPT 的手把手课程，覆盖分词、数据、注意力、Transformer、训练、生成与现代改进。
