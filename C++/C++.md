# C++

## 1.malloc
```c++
void *malloc(int num); 
# 在堆区分配一块指定大小的内存空间，用来存放数据。这块内存空间在函数执行完成后不会被初始化，它们的值是未知的。

```

## 2.堆、栈

```bash
- 栈内存（Stack）：就像你手边的一个一次性托盘。你把要用的洋葱、姜片按顺序放上去。炒完这个菜，托盘上的东西随手就扔掉了（自动清理）。这个托盘空间很小，但拿取极快，一伸手就能够到。

“自动分配释放”：代码跑到这里，内存自己就分出来了；代码一跑完，内存自己“啪”就收回了，完全不用你写代码去删。

“后进先出（LIFO）”：你调用了A函数，A调用了B，B调用了C。那么C一定最先执行完，C的内存先被收回，接着是B，最后是A。就像叠盘子，最后放上去的盘子最先被拿走。

“存储局部变量”：只放那些临时的小东西（比如 int i = 1;）和“指向大对象的门牌号（引用地址）”。




- 堆内存（Heap）：就像餐厅后面的大仓库。你需要从仓库里搬一袋50斤的大米出来用。仓库很大，能放巨多东西，但你需要走一段路去取（速度稍慢），而且用完之后，你必须主动把它放回货架，或者等保洁阿姨（垃圾回收）来收拾，否则就堆满了。

“动态创建”：你只有在程序跑起来那一刻（new 或 malloc），才知道到底要造多大的东西，这个东西就扔进堆里。

“生命周期不由花括号决定”：就算你包着它的那个方法执行完了、花括号结束了，这个对象依然活着，不会自动消失。

“显式释放或GC管理”：要么你手动写代码删（C语言），要么等虚拟机里的“保洁阿姨（GC）”抽空来帮你删（Java/Go）。
```
